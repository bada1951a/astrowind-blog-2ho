## 1. Cuando la barra de notificaciones no responde

Deslizas el dedo desde la parte superior de la pantalla, pero no aparecen las notificaciones ni los ajustes rápidos. O quizá la barra baja a medias, se cierra enseguida o muestra un aviso de que la interfaz del sistema ha dejado de responder. Si te ocurre, entiendo que quieras recuperar cuanto antes controles como el Wi-Fi, el brillo o el modo avión. Yo empezaría por distinguir un fallo puntual de Android de un problema limitado a una zona táctil.

En Android, la barra de estado y el panel de notificaciones forman parte de la interfaz del sistema, que suele identificarse como **System UI**. Un bloqueo puede impedir que el gesto se procese, aunque la pantalla siga mostrando otras aplicaciones con normalidad. No daría por hecho que esa es la causa: una funda que invade el borde, un protector mal colocado, un ajuste de gestos o una aplicación superpuesta también pueden interferir. La idea es comprobar primero lo sencillo y reversible antes de cambiar ajustes o borrar datos.

## 2. Qué puede estar bloqueando el panel

Me fijaría en las pistas. Si la zona superior no responde al tacto también dentro de otras aplicaciones, podría haber un problema con la entrada táctil, el protector o la pantalla; si el resto funciona y el panel falla, gana peso un bloqueo de la interfaz o una incompatibilidad de software. Si ves mensajes de error, animaciones que se congelan o el panel se cierra repetidamente, anota cuándo sucede: por ejemplo, después de abrir una aplicación concreta o activar una función de accesibilidad.

También pueden influir una actualización pendiente, una aplicación recién instalada que dibuja elementos sobre otras aplicaciones, o una personalización del fabricante. No son diagnósticos seguros por sí solos. En cambio, si solo falla el gesto de arriba abajo, pero puedes abrir los ajustes desde el icono de la pantalla de inicio, esa diferencia ayuda a acotar el problema. Yo evitaría instalar una aplicación de “reparación de System UI”: no puede sustituir de forma fiable los componentes del sistema y puede añadir anuncios o permisos innecesarios.

## 3. Tres comprobaciones para recuperar el acceso

1. **Reinicia y comprueba el tacto.** Si puedes abrir el menú de encendido, elige `Reiniciar` y espera a que el teléfono vuelva a arrancar. Si la pantalla está bloqueada, utiliza la combinación de botones indicada por el fabricante; puede variar según el modelo, así que consulta su guía oficial. Después, prueba el gesto desde varios puntos de la parte superior y en orientación vertical. Retira temporalmente la funda, limpia la pantalla con un paño suave y seco y, si es fácil hacerlo sin forzar, prueba sin el protector. No introduzcas objetos en el borde ni presiones con fuerza.

2. **Prueba el modo seguro si el fallo continúa.** Este modo inicia Android sin cargar la mayoría de las aplicaciones descargadas, lo que permite comprobar si alguna está interfiriendo. En muchos modelos, se mantiene pulsada la opción `Apagar` del menú de encendido hasta que aparece `Modo seguro`; en otros, el procedimiento es distinto. Sigue las instrucciones del fabricante si no aparece esa opción. Prueba entonces a desplegar el panel. Si funciona en modo seguro, reinicia con normalidad y desinstala, una por una, las aplicaciones instaladas o actualizadas justo antes del fallo, empezando por las que modifican la pantalla, muestran burbujas o se superponen a otras.

3. **Revisa actualizaciones y ajustes sin borrar datos.** Si puedes abrir Ajustes, busca `Actualización de software` o `Actualización del sistema` y aplica las disponibles con batería suficiente y conexión estable. Comprueba también si el problema coincide con una aplicación concreta y actualízala o desinstálala desde los ajustes habituales. Si necesitas navegar sin el panel, usa la búsqueda de Ajustes o el asistente del fabricante. No borres los datos de `System UI`, no instales archivos de sistema de fuentes desconocidas y no restablezcas el móvil de fábrica como primer recurso.

## 4. Evita cambios arriesgados y valora la ayuda

Durante las pruebas, conserva el acceso a llamadas y a otros métodos para contactar con alguien si dependes del teléfono. Antes de desinstalar aplicaciones, revisa si guardan información local; y antes de cualquier restablecimiento, realiza una copia de seguridad de fotos, documentos y conversaciones según las opciones de cada aplicación. Un restablecimiento puede borrar datos y no es una prueba inicial adecuada para un panel que falla de forma intermitente.

Si el modo seguro no cambia nada, la zona superior tampoco responde en otras pantallas, aparece un aviso persistente de fallo o el móvil se reinicia continuamente, conviene consultar el soporte del fabricante o un servicio cualificado. También pediría ayuda antes de modificar opciones de desarrollador, instalar firmware o abrir el teléfono. Mantener Android y las aplicaciones actualizados y retirar personalizaciones innecesarias reduce algunas incompatibilidades, aunque no garantiza que el problema no vuelva.

## 5. Dudas frecuentes sobre System UI

**Q1.** ¿Que no baje la barra significa que System UI se ha detenido?

**A1.** No necesariamente: un gesto mal detectado, una funda o una aplicación superpuesta pueden producir un síntoma parecido. Si el panel se congela junto con otros elementos del sistema o aparece un mensaje de error, un bloqueo de la interfaz es más plausible. La prueba en modo seguro ayuda a saber si influye una aplicación descargada. Si solo falla una franja táctil en todas las aplicaciones, considera también un problema de pantalla o protector.

**Q2.** ¿El modo seguro borra mis fotos o mis aplicaciones?

**A2.** El modo seguro normalmente no borra tus datos ni desinstala aplicaciones. Lo que hace es iniciar el teléfono con las aplicaciones descargadas desactivadas temporalmente, aunque los detalles pueden variar según el fabricante. Al reiniciar de forma normal, suelen volver a estar disponibles. Si una aplicación causa el fallo, tendrás que localizarla y quitarla por separado.

**Q3.** ¿Debo borrar la caché de System UI o restablecer el móvil?

**A3.** No empezaría por ninguna de esas opciones: borrar datos de componentes del sistema puede afectar a ajustes y no garantiza una solución. El restablecimiento de fábrica elimina información personal, por lo que solo debería plantearse tras hacer una copia de seguridad y seguir las indicaciones oficiales. Antes, prueba el reinicio, el modo seguro y las actualizaciones. Si el fallo persiste, consulta el soporte del fabricante para decidir el siguiente paso.
